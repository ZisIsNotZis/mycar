# 参数化蓝图工具 · 设计（v12 剖面引擎）

目标：一张侧视剖面图，**图上任何一个像素都由参数算出**；校验判据与画面用同一份几何，不可能互相矛盾。

## 1 非目标

- 不做 3D、不做渲染/CAD 精度；这是**概念验证工具**，不是工程图。
- 不做碰撞/强度/法规校核；只保证"看得见的几何自洽"。
- 不追求好看优先于正确：先正确，再美观。

## 2 世界坐标与投影

- 内部**只用毫米**：`x` 从车头保险杠 `x=0` 向车尾增大；`y` 为离地高度，`y=0` 为地面。
- 一次投影：`SX(x) = padL + (x - minX) * k`，`SY(y) = ground + (y - minY) * k`；`k = min(usableW/spanX, usableH/spanY)` 由内容包围盒算出，**不写死**。
- 禁止在任何绘制代码里出现"像素×比例"的混合偏移（v11 的 `18*sc` 就是这个错）。
- 剖面宽度：中线件用**实际宽度**表达（座椅宽、电池宽），投影时按比例转成视觉宽度；外扩件走幽灵层（第 3 节）。

## 3 图层（自下而上）

| 层 | 内容 | 线型 |
|---|---|---|
| L0 车身 | 外轮廓（保险杠/机盖/风挡/车顶/尾门），由参数生成 | 实线 2.5px |
| L1 幽灵 | 轮胎、轮包、地板下方的轮包干涉区 | 虚线 + 低透明度 |
| L2 底盘 | 地板剖面、动力电池、后排包与尾仓下层 | 实线 |
| L3 机构 | 前后座椅、腿托、连杆、中岛、L 型隔板、上铺板 | 实线 |
| L4 人体 | 关节链人体（站/坐/躺） | 实线 + 半透明填充 |
| L5 储物 | 吊柜、前备箱、纱窗/帐篷围幕 | 细实线 |
| L6 标注 | 尺寸线、引出文字、违规红字 | 文字 |

## 5 构件 builder（每个都是纯函数 `p → 图元数组`）

| builder | 输出 | 关键约束 |
|---|---|---|
| `bodyProfile(p)` | 外轮廓多边形 | 上缘 ≥ 座椅头顶 + 30；下缘服从 gf/gr |
| `wheel(p, ax, td, gc)` | 轮胎圆 + 轮包弧（幽灵层） | **轮包弧心 = 轮心**，半径 = td/2 + 60 |
| `floorProfile(p)` | 地板折线 | 中线剖面；跨轮包处不进 L1 幽灵层 |
| `battery(p)` | 电池矩形 | 宽 `bw` ≤ 轮包内间距 |
| `seat(p, 'front'|'rear')` | 坐垫/靠背/腿托/头枕 + 铰点 | 一处实现，`facing` 参数化（决策 D5） |
| `linkage(p, fold)` | 靠背角与腿托角的联动关系 + 连杆 | 决策 D7；`fold=1` 时床面平 |
| `bedAssembly(p)` | 腿托+座垫+靠背+尾台+隔板 的连续床面 | 床长 = 连续平段长度 |
| `occupant(p, pose)` | 关节链人体 | 站/坐/半躺/躺；头永不脱离躯干（决策 D6） |
| `island(p)` | 中岛（杆 + 箱 + 台面） | 旋转模式下杆沉入地板 |
| `partition(p, pAng)` | L 型隔板 | 0/45/90 三档 + 全平 |
| `poptop(p, state)` | 玻璃顶盖 + 帐篷围幕 + 纱窗 + 上铺板 | 三态 闭合/站立/上铺 |
| `lockers(p)` | 两侧吊柜 | 与人体肩宽留 20mm |
| `frunk(p)` | 前备箱腔体 | 说明书第二章 |

## 6 人体（决策 D6）

同一关节表（见 `结构决策.md` D2/D6）驱动三种姿态：

- `stand(y0)`：站在 `y0`（床面或地板）。
- `sit(seatFrame)`：髋在坐垫面上 90；躯干沿**靠背轴线**；大腿沿**坐垫面**；小腿从膝落到地板/踏板面；脚掌平放。
- `lie(x0, y0, tiltDeg)`：足跟→头顶 1750 连续链，`tiltDeg` 支持贵妃榻楔形。

## 8 有效区间色带（回答"滑块难调"）

对每个滑块：固定其它参数，在其范围内等距采样 60 点，逐点跑 C1–C18 的硬判据，把通过区间画成滑块轨道上的绿色段、失败段灰色。拖到绿色外时该滑块立即标红，并提示"先动哪个滑块"。计算量 33×60×18 ≈ 36k 次纯函数求值，单帧内可完成。

## 9 交互与持久化

- 每个滑块配数字输入框（同宽），↑↓ 微调；角度步长 1°，长度步长 5mm。
- 参数与模式：`localStorage` 自动保存 + 导出/导入 JSON + URL hash 分享。
- 预设 = 说明书第九章 6 种形态 + 升顶 3 态，**点击即改参数**（可回退：预设前的状态进撤销栈，支持 Ctrl+Z）。
- 图层开关（幽灵层/标注/人体）便于看清结构。
- 顶部一行实时数字：`L×W×H`、轴距/尾悬、床长/尾台、不升顶总高/升顶总高。
