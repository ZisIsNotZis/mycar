## 附：v13 时代（考古，以下不再作为依据）

目标：一张侧视剖面图，**图上任何一个像素都由参数算出**；校验判据与画面用同一份几何，不可能互相矛盾。

## 1 非目标

- 不做 3D、不做渲染/CAD 精度；这是**概念验证工具**，不是工程图。
- 不做碰撞/强度/法规校核；只保证"看得见的几何自洽"。
- 不追求好看优先于正确：先正确，再美观。

## 2 世界坐标与投影

- 内部**只用毫米**：`x` 从车头保险杠 `x=0` 向车尾增大；`y` 为离地高度，`y=0` 为地面。
- 一次投影：`SX(x) = padL + (x - minX) * k`，`SY(y) = ground + (y - minY) * k`；`k = min(usableW/spanX, usableH/spanY)` 由内容包围盒算出，**不写死**。
- 禁止在任何绘制代码里出现"像素×比例"的混合偏移（v11 的 `18*sc` 就是这个错）。
- 剖面宽度：中线件用**实际宽度**表达（座椅宽、电池宽），投影时按比例转成视觉宽度；外扩件走幽灵层（第 3 节）。

## 6 人体（决策 D6）

同一关节表（见 `结构决策.md` D2/D6）驱动三种姿态：

- `stand(y0)`：站在 `y0`（床面或地板）。
- `sit(seatFrame)`：髋在坐垫面上 90；躯干沿**靠背轴线**；大腿沿**坐垫面**；小腿从膝落到地板/踏板面；脚掌平放。
- `lie(x0, y0, tiltDeg)`：足跟→头顶 1750 连续链，`tiltDeg` 支持贵妃榻楔形。

## 8 有效区间色带（回答"滑块难调"）

对每个滑块：固定其它参数，在其范围内等距采样 60 点，逐点跑 C1–C18 的硬判据，把通过区间画成滑块轨道上的绿色段、失败段灰色。拖到绿色外时该滑块立即标红，并提示"先动哪个滑块"。计算量 33×60×18 ≈ 36k 次纯函数求值，单帧内可完成。

## 9 交互与持久化

- 每个滑块配数字输入框（同宽），↑↓ 微调；角度步长 1°，长度步长 5mm。
- 参数与模式：`localStorage` 自动保存 + 导出/导入 JSON + URL hash 分享。
- 预设 = 说明书第九章 6 种形态 + 升顶 3 态，**点击即改参数**（可回退：预设前的状态进撤销栈，支持 Ctrl+Z）。

- 顶部一行实时数字：`L×W×H`、轴距/尾悬、床长/尾台、不升顶总高/升顶总高。

## 11 v13 新增：逐项体检 `probe()` + `audit.mjs`

- `checks()` 回答**设计规则**过不过（床长、限高、净空…），是用户要看的那一层。
- `probe()` 回答**这份几何自己自洽吗**：车底是否贴在侧裙线上、轮包弧口是否落在侧裙线上、头是否在车壳内、
  人体段长是否等于关节表、床链分段之和是否等于可睡长度、上铺人体是否躺在帐篷里……返回 `[{id,ok,t}]`。
- 两者必须分开：checks 是规则（会随设计意图变），probe 是自洽性（永远该成立）。v13 的 probe 第一批就抓出
  两个真 bug（轮包弧扫向反了、上铺画了第二份人体数学）。
- 用法：

  ```bash
  node scripts/audit.mjs 蓝图-参数化-v13.html [状态文件.json]   # 逐状态打印，退出码 0 = 无 FAIL
  ```

  状态文件 `scripts/audit-states.json`：一组"预设 + 边界情形"的 `{name, patch:{P,M}}`。
- 页面右侧校验面板同样会列出**失败的 probe**（默认只列 FAIL，不刷屏）。

### 3D 导出 + 视频（D65）

v17 是**侧视剖面**引擎，没有 3D；3D 由脚本从 `derive()` 的同一份几何挤出来：

```bash
node scripts/export-glb17.mjs /tmp/mycar-glb17/4460-大床.glb --layout=紧凑 --mode=大床
blender -b -P scripts/blender-render.py -- /tmp/mycar-glb17/one /tmp/mycar-glb17/png 1 900   # 静帧
# 60s 转台（分块并行：4 块各 360 帧 → PNG，再 ffmpeg 拼）
for k in 0 1 2 3; do TOTAL_FRAMES=1440 blender -b -P scripts/blender-turntable.py -- \
  M.glb /tmp/frames 360 960 22 eevee $((k*360)) png & done; wait
ffmpeg -framerate 24 -i /tmp/frames/f%04d.png -c:v libx264 -crf 20 -pix_fmt yuv420p out.mp4
```

- `export-glb17.mjs`：把 `d.solids`（实心件）、`d.shell`（骨架）、`d.beamF/beamR`（上下两排梁）、
  `d.doll`（假人胶囊）挤成棱柱/圆柱，写成单 mesh + 7 个材质分组的 .glb（毫米 → 米）。
  **凹多边形的封盖要拆成凸块**（车壳被拆成机盖/风挡/顶棚三段）—— 否则扇形封盖会漏到多边形外，
  渲出一块大白板（踩过一次）。车身壳体是半透明 `alphaMode: BLEND`，便于看内饰。
