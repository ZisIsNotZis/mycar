# 整车设计（SSOT）

本文件是**唯一的设计真值**。`../sources/整车结构设计说明书-初稿.md` 是最初的种子稿，**已废弃**（保留为 L1 原始材料）。
决策过程与理由见 `结构决策.md`（D1–D42）；实现与判据见 `蓝图工具.md` 与 `蓝图-参数化-v13.html`；介绍视频见 `介绍视频脚本.md`。

## 1 定位

1. **小外廓 · 大内部**：外长 3550 的车里，睡下 1750 的人、站起 1750 的人、装 1.5 m³ 行李。
   "外面小、里面大"不是形容词，是本车所有取舍的判据（v13 起为硬指标）。
2. **分时可变**：通勤、观影、会客办公、三人沙发、睡眠、露营（站立/上铺）共用一车，变形全部纯机械
   （自重 + 人体微力），唯一电动件是升顶（可选）。
3. **储物分脏净**：前备箱（一级脏）→ 尾仓（二级）→ 吊柜（洁净干区）；水相关模块已划出范围（第 9 节）。
4. 硬边界：**不升顶车高 ≤ 2000mm**（限高通行）。

## 3 形态与状态

- **场景预设（7）**：通勤 / 行车观影 / 会客办公 / 三人沙发 / 驻车大床 / 露营·站立 / 露营·上铺。
- **状态量**（可动画过渡，760ms 缓动）：`rot` 前座旋转 0–180°、`fold` 二排变形 0–1、`pAng` 可翻隔板 0–90°、
  `pr` 升顶抬高、`trunk`/`frunk` 门开度、`islLid`/`islBox` 扶手箱两层开度、`islSink` 台面段下沉进度。
- 过渡期间人体隐藏（避免出现过渡姿势），结束后按新状态重画。

## 4 座舱与座椅

1. **前排**：H 点 x=**1610**（用户定值，H 点即靠背铰点）；朝前时坐垫角 20°、靠背角 10°；
   驻车绕座垫中点旋转 180°，**旋转后坐垫角与靠背角一律归零**（用户定：靠背立直 = 床头的挡板），
   座垫/靠背/人体/铰点**同一套镜像变换**。
2. **床链（第 4 条定义，硬判据 C1b）**：
   `前座垫 460 + 腿托 600 + 二排座垫 458 + 二排靠背 300 + 固定隔板 0 + 可翻隔板 290 = 2108 ≥ 1750`
   —— **前座垫是必需段**：前排不旋转，它就不在床面上，判红。床面实测 **2110**，会客净距同时保住 **600**
   （两者由 H 点同时给出：`床面 = 会客净距 + 1460`）。
3. **腿托伸出量是派生量**（恰好跨过脚部空洞，缝恒为 0）；**没有滑轨、没有座椅升降**（D48：省机构）。
4. **二排联动**：`fold` 驱动——靠背放倒（14°→90°）同时腿托顶起（70°→0°），纯机械联动；腿托**可伸缩**：
   收起 300、做床伸出至 430（跨过脚部空洞）。
5. **二排靠背长 300 + 固定隔板 0 + 可翻隔板 180 = 尾仓长 480**（用户第 4 条的方程，C48 守住）：
   靠背铰点是固定点，放平后必须落在尾门之内；可翻隔板从靠背尾端开始（"start back-er"）。
6. **二排半躺的几何天花板 ≤ 20°**：再躺头就穿后风挡（判据 C47）。想要更躺就要 `rearInset` 更小或车更长。
7. **三人沙发**：前排旋转 180° + 扶手箱层 1 翻开当靠背（第 7 节），两侧座垫 + 中排薄坐垫连成一排。
8. **站立 / 上铺**：站立要求 `床面 + 1750 + 60 ≤ H + pr`（默认需 pr 720）；净空不足时按说明书降级为坐姿。
9. **前排在 H 点 1610 下的三个软提醒**（不是失败，是已知取舍）：坐垫前缘 1178 压在前轮包上（后缘 1240）、
   脚尖 1127 落在前轮位切片内、坐垫角 20° 使小腿差 104mm 够不到地板（降 `fLift` 到 -60 可消）。
   要三条全消就把 `xF` 后移到 ~1780（代价：床面 -170）。

- 吊柜底 = H − 300；要求坐姿头部不碰（判据 C14）。

## 6 底盘与三电

1. **动力电池**：1250–2100（850 长）× 宽 1200 × 厚 320 = **52 kWh / 326 L**；
   窄到能从左右轮包之间穿过（判据 C29）。地板 = 前离地 + 电池厚 = 460。
2. **轮位切片全被占满**：前=转向/48V/AC + 溃缩件，后=同轴三电。图纸以红色包络表达。
3. 整车重心在轴距内。

## 7 中岛 = 中央扶手箱（三层机构，D39）

| 层 | 件 | 常态 | 变形后 |
| --- | --- | --- | --- |
| 层 1 | 台面板（薄板，铰在前缘） | 水平，顶面 1080（餐桌高，比座面高 320） | 翻开 ≥80° = **中排靠背**；随套筒下沉 = 与座面齐平 |
| 层 2 | 箱盖 / 薄坐垫 | 座面高（810/750） | **中排坐面**：与前两座齐平 → 三人沙发；翻开 = 开箱 |
| 层 3 | 箱体 | 地板 → 座面高 | 盖由**撑杆托住**（信箱式） |
| 套筒 | 台面段整体下沉（进度 0–1） | 0 | 1 = 恰好沉到座面 → 床前段变**全宽** |

- 层 1 板宽 220 < 人肩 460：靠背受力由两侧座垫边缘分担（用户原话："so no worry that much"）。

## 8 升顶与投影

1. **升顶三态**：闭合 / 站立 / 上铺。玻璃顶盖整体上抬 + 帐篷围幕 + 纱窗；第三层**不承重**，只有四周壁面与**顶横梁 ×2** 可受力。
2. **开口**：铺满车顶（内缩只留 30）：默认 1150–3080（1930 长）；床面可站立区 1930 ≥ 1200。
3. **上铺**：内腔 1870 ≥ 1750 → **能睡成人**（不放人时自动降级为小孩）；人体锚点由帐篷内腔**反解**，
   人永远躺在帐篷里（v12 的"脚伸出帐篷"是画了第二份人体数学导致的）。
4. **投影**：卷帘幕布挂在前顶横梁（scrX 1300），投影仪在车尾（pjX 2980，必须在车壳内，判据 C38）；
   幕布宽度上限 = 吊柜之间净宽 1140（51″/16:9，投射距离 1680 ≥ 所需 1368）。
5. **光锥**：全宽可翻隔板抬起时会挡光锥（C36）；坐姿乘客在两侧、不挡（提示 C37）。
6. **尾门**：两段折叠式（上段 909 / 下段 776），铰点在投影仪那一带的车顶后缘；开到位时整体退到车尾之外。

## 9 隔板（一板多用）

1. **固定隔板 / 二层平台**：恒为床面一段，**默认为 0**（由可翻隔板无缝接管）。
2. **可翻隔板**：铰在后段，**0° 平铺补床尾**、**45° 作贵妃榻靠背**、**90° 立起成尾柱隔断**（净高 ≥900，可放两层货）。
   长度受尾门封顶（默认 100）。

## 10 边界与超范围

- **超范围**：水相关模块（可冲洗湿区、应急淋浴、排水集水）——不做，图纸与判据均不涉及。
- 不做 3D 碰撞/强度/法规校核；工具只保证"看得见的几何自洽"。

## 12 判据体系（工具内 50 条 + 逐项体检）

- 硬约束（必须全绿）：床链 ≥1750 且含前座垫、床面/座面齐平与无缝、站姿/上铺/坐姿净空、头顶不穿顶、
  **头不穿风挡/后风挡（C39/C47，用真斜线）**、床面高于后轮包、腿托不碰前排、会客净距 ≥600、
  电池避轮包、投影仪在车内、垫板不挡光锥、**中岛不顶床**、**上铺人躺在帐篷内**、吊柜间距 ≥肩宽、限高 2m、
  **前/后溃缩长度**、**靠背放平后落在尾门内（C48）**、**躺姿完整落在床面上（C50）**。
- 提示与信息：脚部地板净空、轮位切片占用、储物体积明细、被几何夹住的靠背角。
- **逐项体检 `probe()`**：与 checks 分离的"这份几何自己自洽吗"（车底平不平、弧口在侧裙线上、头在车壳内、
  人体段长、床链分段、帐篷内腔…），`scripts/audit.mjs` 逐状态打印。checks 管设计规则，probe 管图的自洽。
