# 整车设计（SSOT）

本文件是**唯一的设计真值**。决策与理由见 `结构决策.md`（D1–D60；v13 时代的条目是历史，`D56` 起才是本模型）。
工具、文件与验证约定见 `蓝图工具.md`。当前工作文件是 **`蓝图-v17.html`**；
`蓝图-参数化-v13..v15.html`、`蓝图-分层坐标-v16.html` 是迭代考古，不改不删、不作为依据。
`../sources/整车结构设计说明书-初稿.md` 是最初的种子稿，**已废弃**。

## 1 定位与硬边界

1. **小外廓 · 大内部**：外长短，但能睡下 1750 的人、站起 1750 的人。所有取舍都服从这一条。
2. **分时可变**：通勤、对坐会客、观影、大床/小床、露营站立/上铺共用一车；变形全部纯机械，唯一电动件是升顶。
3. **硬边界**：**不升顶车高 ≤ 2000mm**（限高通行）；升顶只在驻车开启，不受此限。
4. **只画全宽件**：车壳、玻璃、轮子、中岛、吊柜、单人座椅等非全宽件不出现在图上（它们是后算的，不是设计输入）。
5. **范围外**：一切与水有关的东西（清洗/排水/防霉）；不做滑轨、不做座椅升降（对齐靠设计，不靠机构）。

## 2 坐标系：三层零坐标链

`x = 0` 是车头，`x = L` 是车尾（L 是**派生量** = 层A 链之和）。
每层内部是一条**首尾相接的链**（层内接缝恒为 0），层与层靠 y 分段，所以结构上不可能互相压。

| 层 | y 区间 | 内容 |
| --- | --- | --- |
| 层A 底盘 | y0 … 各自的顶 | 全宽底盘件：前备箱 / 前机能体 / 电池 / 后机能体 / 尾仓 |
| 层B 座舱 | y1 … y3 | x10 前部上段（前备箱高段）· 前脚空间 · 前座 · 后脚空间 · 后座（+ 派生的靠背放平预留、可翻件） |
| 层C 升顶 | y3 … y4 | 开口前留白 + 升顶开口（长派生）+ 后端最小留白 |

**规则参数（D64，优化器不许动）**：`bmF` `bmR` `bmK` `knG` `cltc` `eff` `pDen` `battW` `ws` `wD` `axF` `axR`。

**Y 高度（8 个参数）**：`y0` 底盘底 · `y1` 舱内地面 · `y1a` 前机能体顶面 · `y1b` 后机能体顶面 ·
`y1c` 前备箱顶面 · `y2` 床面 = 座面（座面是派生量，不做升降）· `y3` 顶棚 · `y4` 升顶顶棚。

**X 层A（5 个参数）**：`x00` 前备箱低段（车头，腔内有穿过的溃缩梁）· `x01` 前机能体（**前备箱高段在它之上**）·
`x02` 电池 · `x03` 后机能体（**尾仓高段在它之上**）· `x04` 尾仓低段（顶 = 床面）。
前备箱与尾仓都是**两段宽度**的 L 形腔体，各有自己的长度；`x10`、`x15` 与 `x01`/`x03` **无推导关系**。

**X 层B（6 个参数）**：`x10` 前部上段 = 前备箱高段（**独立值**，可长于/短于 x00+x01）·
`x11` 前脚空间 · `x12` 前座空间 · `x13` 后脚空间 · `x14` 后座空间 · `x15` 尾仓上段长（后机能体之上，**独立值**）。

**X 层C（2 个参数）**：`x30` 开口前留白（必须在风挡/仪表台之后）· `xBeam` 顶中间横梁 x 位置（截面 80×60，**梁顶 = y3**）。

**我定（4 个参数）**：`W` 内宽 · `bckT` 靠背厚 · `fBa` 前排靠背角（坐姿）· `rBa` 二排靠背角（坐姿）。

## 3 派生量（**不设参数**，所以构造上不可能互相矛盾）

- **车长 `L` = x00+x01+x02+x03+x04**
- **座面 = 床面**（靠座垫厚对齐）
- **靠背放平预留** = 二排靠背（含头枕）= 一个矩形 740
- **可翻件（隔板）**：铰点 = 二排靠背放平后的尾端，长度 = 到车尾
- **腿托**：伸出后恒填满「前排座椅后面 → 二排座垫前缘」的空缺（顶住前排，与前排是否旋转无关）
- **升顶开口长** = `L − x30 − 60`；后端只留最小结构 60
- **床面前界**：床模式前排靠背一律**立直**（= 床头板）→ 反转时 = 座垫前缘，未反转时 = 座垫后缘 + 靠背厚
- **上铺板**：铺面 = y3，横跨升顶开口（真实构件，画出来 + 参与碰撞）
- **顶中间横梁**：位置是参数 `xBeam`，截面与高度（y3）是常量
- 车壳、轮子、玻璃、家具：后算，不画不参数

**溃缩结构（D64）**：前后各**上下两排** —— 上排（前 `x10` / 后 `x04+x15`，从头/到尾量，坐在 y1 一带的腔底）
≥ `bmF`/`bmR`；下排（前 `x00` / 后 `x04`，在 y0 一带）≥ `bmK`×上排；两条都是**下限**（可以更长）。

**骨架 + 轮（D64，视图开关）**：车壳 = 地面/车头/机盖/风挡(`ws`)/顶棚/尾门；轮 ⌀`wD` 在 `axF`/`axR`（幽灵层）。
**只读参数、不读机构状态** —— 点预设时骨架不动。

**车长恒等式**（`scripts/shrink.mjs` 复核过；是模型的形状，不是新决定）

```text
L    = (x10+x11) + 床长                          ← 「车头→前排」+ 床
床长 = (x12+x13+x14) + 740 + C13余量 + x04
x00+x01+x02+x03 = (x10+…+x14) + 740 + C13余量   ← 前机能体+电池那一段不是自由量
躺姿头部：C13余量 + x04 ≥ 890
尾段夹逼：890 ≤ C13余量 + x04 ≤ 1090      ← 下界是躺姿的头，上界是 C8（可翻件立起来不捅穿顶棚）
```

含义：`x01/x02/x03` 只有**和**有意义（怎么分摊不影响车长）；缩车只有两条路 ——
缩「车头→前排」段或缩「后排座舱 x12..x14」段，再加上车尾必须留的 890。

## 4 机构状态与预设

**机构状态（4 个开关，各有"常规位"；不是参数）**
`rot` 前排旋转 朝前/朝后 · `fold` 二排 坐姿/放平 · `pAng` 可翻件 立 90°/放平 0° · `popUp` 升顶 降/升。

**预设 = 状态的组合（顶部按钮条）**常规 · 对坐（前排旋转但不下床）· 大床（= 前排旋转 + 二排放平 + 隔板放平）· 大床观影（隔板 45°）·
小床（= 大床但不转前排）· 小床观影 · 升顶 · 升顶站立。切换走 760ms 缓动；过渡帧不画假人。

**布局 = 一整套参数快照（第二排按钮条「布局」）**：来自 `scripts/shrink.mjs` 的缩小实验结果
（不同溃缩梁长度下的最小车长，D61/D62）；点一下套用整套参数，机构状态不动。

## 5 人体与物理（布偶 PBD）

- 人 = **6 个带半径的粒子 + 5 条距离约束**（踝/膝/髋/肩/头/趾；小腿 400、大腿 420、躯干 520、肩-头 215、足 80），
  **关节角自由**。人体只有这一套（坐/躺/站/上铺都用它）。
- 姿势**不是解出来的，是物理算出来的**：重力 + PBD 投影（距离约束 → 硬实心体推离 → 软垫单向支撑），
  dt 1/120、每帧 4 子步；带静摩擦、阻尼、限速。状态变化后自动落定 2.2s。
- **鼠标可以拖关节**（拾取最近粒子 → 临时钉住 → 松开释放）；「落下 / 稳定」按钮 = 抬到 +800 再演进（从天上丢下来）。
- **人 vs 人允许重叠**（人不是全宽件）；人与**硬实心体**一律不许穿；软垫（座垫 / 腿托 / 可翻件 / 放平靠背 / 上铺板）可压。
- **升顶站立**的人由一根**可见的绳子**吊住头顶（最大长度约束；锚点在 y4，绳长 130）—— 证明是真实物理而非画出来的姿势。

## 6 画图规矩

- 只画全宽件；只画**物理上真实存在**的东西（自造的示意面、绿虚线、零长隔板一律不要）。
- **图里不出现绿色**；高度参考线用中性色/蓝。
- 文字一律在图**上方**，图下不留字。
- 座垫/靠背/腿托/可翻件一律画在 y2 **之下**：y2 就是坐/躺的那个面。
- 溃缩梁按侧视画：一组 = 左右两根并行 → 侧视只看得见一根；前备箱低段与尾仓低段各一组。
