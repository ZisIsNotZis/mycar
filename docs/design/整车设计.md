# 整车设计（SSOT）

本文件是**唯一的设计真值**。`../sources/整车结构设计说明书-初稿.md` 是最初的种子稿，**已废弃**（保留为 L1 原始材料）。
决策过程与理由见 `结构决策.md`（D1–D33）；实现与判据见 `蓝图工具.md` 与 `蓝图-参数化-v12.html`。

## 1 定位

1. **极小外轮廓容纳分时可变内部空间**：通勤、观影、会客办公、睡眠、露营共用一车。
2. **变形全部纯机械**（自重 + 人体微力），不依赖电动执行机构；唯一电动件是升顶（可选）。
3. **干湿脏分层储物**（水相关模块已划出范围，见第 9 节）。
4. 硬边界：**不升顶车高 ≤ 2000mm**（限高通行）。

## 3 形态与状态

- **场景预设**：通勤 / 行车观影 / 会客办公 / 驻车大床 / 露营·站立 / 露营·上铺。
- **状态量**（可动画过渡，760ms 缓动）：`rot` 前座旋转 0–180°、`fold` 二排变形 0–1、`pAng` 可翻隔板 0–90°、
  `pr` 升顶抬高、`trunk`/`frunk` 门开度。
- 过渡期间人体隐藏（避免出现过渡姿势），结束后按新状态重画。

## 4 座舱与座椅

1. **前排**：H 点 x=1850；驻车可绕座垫中点旋转 180°（旋转轴在座垫中点 → 占地不变）；
   座垫/靠背/人体**同一套镜像变换**（铰点也镜像，否则靠背翻错端）。
2. **二排联动**：`fold` 驱动——靠背放倒（14°→90°）同时腿托顶起（70°→0°），纯机械联动；
   坐垫角随放平归零。腿托**可伸缩**：收起 300、做床伸出至 600（跨过脚部空洞）。
3. **床**：前座垫 + 腿托 + 二排座垫 + 二排靠背 + 固定隔板 + 可翻隔板，**最大 2628**（默认坐姿状态 2160）。
   做床必须旋转前排（否则腿托插进靠背）；床面与前座面齐平（差 0）。
4. **贵妃榻**：隔板抬 45° 时躯干沿隔板倾角；**隔板抬到 90° 时改当椅背**（人坐在床面、脚落地板）。
5. **站立**：床面 + 1750 + 60 ≤ H + pr（默认需 pr 720）；净空不足时按说明书降级为坐姿。
6. 前排脚必须落在前轮位切片之外 → 由 `fLift`（前座升降）把脚往后拉，配合 xF=1850。

| ④ | 中岛箱体（中央通道） | 520×? × 220 | **96 L** |

- 前备箱为**一级脏区**；下层仓为**二级**；吊柜为**洁净干区**（衣物寝具电子设备）。
- 吊柜底 = H − 300；要求：**坐姿头部不碰**（人头顶 ≤ 吊柜底 − 30，判据 C14/C6）。

## 6 底盘与三电

1. **动力电池**：1250–2410（1160 长）× 宽 1200 × 厚 320 = **71 kWh / 445 L**；
   要求与前后轮包各留 ≥150mm，或窄到能从左右轮包之间穿过（判据 C29）。
2. **轮位切片全被占满**：前=转向/48V/AC + 溃缩件，后=同轴三电（电机+减速+逆变）。图纸以红色包络表达。
3. 整车重心在轴距内；地板 = 前离地 + 电池厚。
4. 前备箱由**正面双溃缩大梁**横贯（大梁保留，空腔自避让）。

## 7 升顶与投影

1. **升顶三态**：闭合 / 站立 / 上铺。玻璃顶盖整体上抬 + 帐篷围幕 + 纱窗；第三层**不承重**，
   只有四周壁面与**顶横梁 ×2** 可受力（上铺板搭在顶横梁上）。
2. **开口**：尽量铺满车顶曲率（默认 1700–3550），床面可站立区 ≥1200。
3. **投影**：卷帘幕布挂在前顶横梁，投影仪在车内后部（**必须在车壳内**，判据 C38）；
   幕布宽度上限 = 吊柜之间净宽 = **1140**（所以是"被车宽卡住"而不是"被距离卡住"）；
   默认 51″ / 16:9 / 投射距离 1410 / 投射比 1.2（短焦）。
4. **光锥**：全宽的**可翻隔板**抬起时会挡光锥（判据 C36）；坐姿乘客在两侧、不挡（提示 C37）。

## 8 隔板（一板多用）

1. **固定隔板 / 二层平台**：靠背放平尾端 → 可翻隔板铰点，恒为床面一段（**可以为 0**，由可翻隔板无缝接管）。
2. **可翻隔板**：铰在后段，**0° 平铺补床尾**、**45° 作贵妃榻靠背**、**90° 立起成尾柱隔断**（可放两层货，净高 ≥900）。
   长度 ≤ 到车尾的距离（超出自动封顶）。

## 9 边界与超范围

- **超范围**：水相关模块（可冲洗湿区、应急淋浴、排水集水）——不做，图纸与判据均不涉及。
- **未定**：上铺板的具体尺寸（暂取开口长 −100、搭在顶横梁上）。
- 不做 3D 碰撞/强度/法规校核；工具只保证"看得见的几何自洽"。

## 10 判据体系（工具内 41 条）

硬约束（必须全绿）：床长能力与当前配置、固定隔板、尾柱净高、站姿/上铺净空、坐姿净空、头顶不穿顶、
床面高于后轮包、腿托与前排真碰撞、铰点镜像后的小腿不穿靠背、前座与床齐平无缝、会客净距 ≥600、
电池避开轮包 ≥150、门/开口有效、幕布与投射距离、投影仪在车内、垫板不挡光锥、吊柜间距 ≥肩宽、限高 2m。
提示（不影响绿）：脚部地板净空、轮位切片占用、储物体积、关键指标。
公式化的阈值全部在 `蓝图工具.md` 与工具源码里，不在此重复（SSOT 单一来源）。
