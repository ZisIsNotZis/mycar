# 介绍视频脚本（v1 待审）

对象：一台 3550×1800×1900 的分时可变座舱跨界车。目的是**发布级介绍片**，不是说明书。
本稿含：镜头/旁白/字幕三轨 + 工具链决定 + 诚实代价段。**先审文本，通过后再进渲染。**

## 1 基调与规格

- **一句话主张**：外面小，里面大（Small outside. Big inside.）——全片所有画面都在证明这一句，也在交代代价。
- **风格**：Apple 发布会短片语法——**全程零硬切**、平滑运镜、冷静、留白、按顺序交代"改了什么/为什么/怎么做/代价"。
- **时长**：4:15（旁白 ~1000 字，中文语速 4.4 字/秒）。先做 **60 秒预告版**验证管线，再做全片（见第 6 节）。
- **规格**：3840×2160 · 24fps · 交付 MP4(H.265) + 旁白 WAV + 字幕 SRT。
- **观众**：会算账的潜在用户（关心停车、露营、睡觉、装东西），不是工程师。

## 2 工具链决定（本机已实测）

| 环节 | 选型 | 依据 |
| --- | --- | --- |
| 几何真值 | **蓝图 v13 的 `build()/build3D()`** | 唯一一份数学；视频不许自己建模 |
| 逐帧烘焙 | 新脚本 `scripts/bake-frames.mjs`：按帧采样状态 → 导出**图元 JSON**（不是逐帧 GLB） | 逐帧 GLB 需 6000+ 文件且无法插值；JSON 让 Blender 拿真对象做关键帧 |
| 渲染 | **Blender 4.5.13 + EEVEE-Next（主）/ Cycles+OptiX（预告级特写）** | 本机 RTX 4090 24G；EEVEE 4K 约 0.3s/帧（全片 ≈30 分钟），Cycles 4K 64 采样约 2–4s/帧 |
| 配音 | **edge-tts**（已实测可用：`zh-CN-YunyangNeural` 新闻/可靠、`zh-CN-XiaoxiaoNeural` 温暖女声） | 免 key、免 API、中英双语可用；不用人声录音 |
| 合成 | **ffmpeg**（已装）：拼接 + 人声/音乐侧链闪避 + 烧字幕 | 无需额外软件 |
| 音乐 | 待定（见第 7 节）：CC0 曲库优先；不可达时用 ffmpeg 合成氛围垫底 | 版权是唯一的硬阻塞项 |

- **人体**：不做行走动画（用户判断正确，也太贵）。做法：关节链（蓝图里已有）→ 6 个胶囊 + 1 个头球，
  **淡入淡出**（0.6s 材质不透明度）代替走位；只做"坐着/躺着/站着"的静态姿态。**完全可行**，不是妥协。
- **外壳**：允许"车壳变透明/剖切"作为运镜手法（蓝图 3D 已有不透明度与剖切两档），镜头因此可以穿进车里。

## 3 视听语法（"永不硬切"的实现规则）

1. 每一次场景变化都是**运镜**：推、摇、升降、环绕、穿壳；全片只有 4 次**12 帧交叉溶解**，
   都发生在"必须换空间"的地方（例如车外 → 车内）。
2. 文字：淡入 + 轻微上移（8 帧），永不弹出、永不闪现。
3. 人体：淡入淡出；变形过程中人体**先消失再出现**（和蓝图工具的规则一致，避免出现过渡姿势）。
4. 变形件（座椅/腿托/隔板/顶盖）在片子里**同步**运动：一次变形只用一个缓动曲线，
   让观众看见"一根连杆驱动两个动作"的机械因果。
5. 音频连续：旁白与音乐床贯穿全片；机械动作配**真实感音效**（连杆咔哒、顶盖电机、隔板锁止）。
6. 色彩：冷灰工作台 → 黄昏城市 → 暖光车内（睡眠段）→ 清晨。三段光色即三段时间。

## 5 旁白全文（可直接喂 edge-tts）

> 每段前的 `[Sx]` 是分镜编号；`(` `)` 内是停顿提示，不进配音。

```text
[S1] 每台车都在做同一道选择题：要么好停，要么好用。(0.6s) 三米五的车身，通常意味着你得放弃睡在里面；能睡下的车，往往停不进你家车位。(0.5s) 我们想试一次，不给这道题留退路。
[S2] 这是它。长三千五百五十毫米，宽一千八百，高一千九百——比一台紧凑两厢车还短。(0.4s) 但里面是一张两米一的床，可以站直，可以睡两个人：一个在下，一个在上。(0.5s) 而这些变化，没有一个是电机驱动的。
[S3] 从最普通的状态开始。(0.4s) 二排靠背放下的同时，腿托升起：一根连杆，两个动作，一次到位。
[S4] 前排座椅绕自己做一百八十度旋转，占地不变。(0.4s) 两排之间留出六百毫米——一块桌板，四个人可以对面坐下。
[S5] 扶手箱的第一层翻开，就是中排的靠背；第二层放平，和两侧座椅连成一排沙发。(0.4s) 板比人窄，受力交给两侧座垫。
[S6] 做床的时候，台面段整段沉到座面高度，前排座垫接上床面——床的前段从此是全宽的。
[S7] 唯一用电的地方是车顶。(0.4s) 抬起来之后你在车里可以站直，头顶还剩六十毫米。
[S8] 上铺的板从尾仓抽出来，搭在两侧壁面和顶横梁上。(0.4s) 开口铺满整个车顶，长一千九百三十毫米，够睡一个成年人。
[S9] 六个储物位，按脏净分层。(0.3s) 一级脏区在前备箱，五百六十五升，泥靴湿具直接扔进去；二级在尾仓下层，五百五十五升；两侧吊柜三百六十七升，只放干净衣物寝具和电子设备；扶手箱和座下抽屉放日常零碎。(0.4s) 还有一个临时高尾仓——但那里平时是你的床。
[S10] 我们把车缩短了五百五十毫米，代价写在明面上：储物从二点一立方掉到一点六立方；二排靠背最多躺二十一度，再往后头就穿过后风挡了；前排旋转后的贵妃榻最多十七度，风挡就在头顶；轴距一千六百五十毫米，很短；五十二度电，够城市和周末，不够长途。(0.5s) 这不是缺陷清单，是设计清单——每一条都对应我们明知换到了什么。
[S11] 一台三点五五米的车，睡得下一米七五的人，站得起一米七五的人。(0.5s) 外面小，里面大——这不是把空间变出来的魔术，是把每一毫米都问一遍的结果。
```text

- 总字数 ≈ 1010，配 4.4 字/秒 ≈ 3:50，加上 `(停顿)` 与镜头留白 ≈ **4:15**。
- 数字一律读汉字（"三千五百五十"），避免 TTS 读成阿拉伯数字的怪异停顿。

## 6 落地计划（三步，每步都有可交付物）

1. **预告版 60 秒**（只做 S1+S2+S6+S11）：验证 `bake-frames.mjs → Blender 关键帧 → 运镜 → edge-tts → ffmpeg` 全链路，
   交付 60 秒无声/有声两版。**这一步就能看出"零硬切"在成片里成不成立。**
2. **全片 4:15**：补 S3/S4/S5/S7/S8/S9/S10，加音效与音乐。
3. **可选**：竖版 9:16 剪辑（社交平台）+ 英语配音版（同一个脚本换 voice）。

需要新建的资产（都不大）：

| 资产 | 说明 |
| --- | --- |
| `scripts/bake-frames.mjs` | 按帧采样 `MY.build/MY.build3D` → `frames.json`（每帧图元 + 人体关节） |
| `scripts/blender-film.py` | 读 `frames.json` → 建对象 + 材质 + 每帧关键帧 + 摄像机路径 + 灯光 + 渲染 |
| 人体模特 | 关节链 → 胶囊/球，材质可淡入淡出（蓝图已有 `bodyJoints`） |
| 音效 | 连杆、顶盖电机、锁止、帐篷布——可用 ffmpeg 合成或 CC0 素材 |

## 7 待你拍板（这几条会改变成片）

1. **配音语言**：中文（上面这版）还是英文？TTS 两种都行；发布会质感通常英文更"Apple"，但你的受众？
2. **音色**：`zh-CN-YunyangNeural`（男·新闻·可靠）还是 `zh-CN-XiaoxiaoNeural`（女·温暖）？英文对应 `en-US-AndrewNeural` / `AvaNeural`。
3. **音乐**：需要一首授权干净的曲子。三个选项：① 你提供；② 我去找 CC0 曲库（本机网络可能受限，需你确认可达）；
   ③ **不要音乐**——只留旁白 + 机械音效（更冷、更"工程"，我个人推荐先做这个版本）。
4. **人体**：淡入淡出的模特（推荐）；或者干脆**不出现人**，只用尺寸标注说明"睡下一个 1.75 米的人"（更干净，也更难被打脸）。
5. **代价段的尺度**：现在这版把三条硬代价都摆上桌（储物、两个靠背角、电池）。要不要再点一句"短轴距"之外的其他取舍？
6. **长度**：4:15 全片 + 60 秒预告，还是先只做 60 秒？
