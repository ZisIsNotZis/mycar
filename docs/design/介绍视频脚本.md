# 介绍视频脚本（v3 · 车长 4460 的紧凑布局）

> v2（3350 车的旧稿）已在 git 历史里，不再作为依据。本稿的数字全部来自当前引擎
> （`蓝图-v17.html`，默认/紧凑布局，D61–D64 的规则下八预设硬判据全绿）。

产品名：**my car**。对象：**L 4460 · W 1800 · H 1900** 的分时可变小房车（大床 2770 · 站立净空 1830）。
基调：**英文旁白 + 双语字幕（中文主行 + 英文小字）**、男声"美食节目"语气、慢、不推销。

## 1 主张与规格

- **主张**：*Small outside. Big inside.* —— 外面是紧凑级，里面睡 1750 的人、站 1750 的人。
- **本片特有的一条**：前后溃缩结构 **1240 / 1150** 是用户拍板的真车安全量（D62）。
  于是"车能缩到多小"变成一个可以用引擎算的问题（D61：`L = 座舱链 + 1630`）。
- 规格：**1920×1080 · 24fps · H.264 + 旁白 AAC + 双语字幕烧进画面**，片长 **81 秒**。
- 旁白：`edge-tts` `en-US-AndrewNeural`，`--rate=-8%`（慢一点），**带退避重试**（`scripts/gen-vo.sh`）。
- BGM：本地合成（`scripts/film-music.sh`，无版权问题），只在转场处进出、说话时压到很低。
- 人体：引擎的布偶物理落定后的**静姿**，只做淡入淡出（不做行走/不插值姿势）。

## 2 工具链（本机实测）

| 环节 | 选型 | 备注 |
| --- | --- | --- |
| 几何真值 | `蓝图-v17.html` 的 `derive()` | 视频不许自己建模 |
| 逐帧烘焙 | `scripts/bake-frames17.mjs` → `frames.json` | 车/人/相机逐帧；零件键每帧都在（否则会被常量外推） |
| 渲染 | Blender 4.5.13 · EEVEE-Next · 48 采样 + 光线追踪 + 运动模糊 | 1920×1080 ≈ 0.25s/帧/进程 → 4 块并行约 8 分钟 |
| 旁白 | `edge-tts`（`scripts/gen-vo.sh` 退避重试） | |
| 配乐 | `scripts/film-music.sh` | 12 秒软垫摆在转场点 |
| 合成 | `scripts/film-assemble.sh`（烧双语字幕 + 旁白） | |

**画面语言**：车壳做成**半剖模型**（近侧那半被剖切面拿掉、剖切面那侧不封盖）——
比整车半透明干净得多，也是本项目"侧视剖面"的老规矩。

## 4 旁白全文（喂 edge-tts 的原文）

```text
Hello — this is my car. Four metres forty-six long, with a real crash structure at each end.
Twelve hundred and forty millimetres in front. Eleven hundred and fifty behind. Everything human has to fit between them.
Four seats, a table, and headroom to stand up in. Then the rear bench folds flat.
The leg rest rises with it — one linkage, two movements. The front seats turn around, and the bed runs from the windscreen to the tailgate.
Two metres seventy-seven of bed, and one person asleep in it. Longer than the person: that is the point.
Raise the roof — the only motor in the car — and you can stand up. One metre eighty of headroom above the mattress.
Now look underneath. The wheels do not move. The body, the seats, the bed — free to change. The axles are not.
So how small can it get? Same wheels, same seats, same adult-sized bed — and the car is three hundred and eighty millimetres shorter.
Same car. Same wheels. Small outside, big inside. This is my car.
```

一句话一条，正好对上 9 个分镜；实测旁白 **67.1 秒**（`--rate=-8%`），片长 81 秒，尾部留 5 秒 BGM 收尾。

## 5 复现

```bash
node scripts/bake-frames17.mjs /tmp/mycar-film/frames.json          # 烘焙 1944 帧
for r in "1 500" "501 1000" "1001 1500" "1501 1944"; do set -- $r;  # 4 块并行渲染
  FILM_SAMPLES=48 FILM_RT=1 blender -b -P scripts/blender-film.py -- \
    /tmp/mycar-film/frames.json /tmp/mycar-film/full $1 $2 1920 eevee & done; wait
bash scripts/gen-vo.sh vo.txt vo.mp3                                # 旁白（带重试）
bash scripts/film-music.sh vo.mp3 81 /tmp/mycar-film/mix.wav 25,45,63,73
bash scripts/film-assemble.sh /tmp/mycar-film/full mix.wav subs.srt out.mp4 24 1920
```
