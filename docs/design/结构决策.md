# 结构决策记录

记录**已拍板**的设计决定、理由、以及被否掉的选项。设计描述以 `整车结构设计说明书.md` 为准；这里只记"为什么"和"边界"。
状态标记：`已拍板`（用户明确确认）· `代决`（代理按说明书与约束代做，用户可否决）· `待定`。

## D1 车高预算：不升顶时 ≤2000mm `已拍板`

- 约束来源：限高通行（地库/限高杆 2m）。
- 推论：**任何"把地板/座椅整体抬高"的方案都被否决**，因为它会连锁抬高顶棚。
- 落地：`H` 滑块上限 2000，`H > 1980` 给出限高警告；升顶只在驻车开启，不受此限。

## D2 升顶（第三层）的用途：站立 + 上铺，两者都要 `已拍板`

1. **开顶形态**：玻璃顶盖像 Tesla 那样整体上抬（面积更大），四周拉起帐篷布（带纱窗帘），结构上第三层**不承重**，只有**四周壁面 + 顶横梁**可以受力。
2. **用途 A · 站立**：升顶后可以**站在床面上**（床面 660 → 头顶 2410）。不升顶时床面上方净空只有约 1000mm，**只能坐**。
3. **用途 B · 上铺**：从下层仓抽出两块硬质隔板/铺板，两端搭在**两侧壁面 + 顶横梁**上，形成上铺；可睡 1 大人 + 1 小孩。
- 落地：升顶三态 `闭合 / 站立 / 上铺`；开口 `px0..px1` 独立参数；`pr` 范围放宽到 250–900。
- 待定：上铺板的具体高度（暂取原车顶面 1660–1700 区间）与板长（暂取开口长度 −100）。

## D3 前排脚坑 / 前轮包：不抬升任何东西，改用图层表达 `代决`

- 背景：v11 把外扩的轮包和中心线剖面画在同一张不透明图上，看起来像"电池和前脚插进轮子里"。
- 事实：侧视图是**中心线剖面**；轮包在车外两侧，3D 上不冲突（电池宽 W−410，双脚在左右轮包之间）。
- 决定：
  1. 轮胎与轮包画在**幽灵层**（虚线/半透明），中线件（地板、电池、座椅、人）才是实线剖面。
  2. 删掉"电池前缘 ≥ 前轮包"这类**侧视 x 判据**，改为**宽度判据**：电池宽 ≤ 左右轮包内间距；座椅宽 ≤ 轮包内间距。
  3. 保留"前排坐垫前缘在轮包之后"为**软提示**（△ 而非 ✗）：真车允许座椅压在前轮包上，只是会挤占脚部横向空间。
- 理由：满足 D1（不抬升），且修正 v11 的错误物理断言。

## D4 前悬 `oh` 与轴位 `axF`：合并为一个量 `代决`

- `oh` 与 `axF` 描述同一个几何（保险杠在前轴前多少），v11 却把它们当两个独立参数，必然互相打架。
- 决定：删除 `oh`。车头基准 `x=0`，**前悬 = axF**（前轴位置），车头造型由造型参数（机盖高度、风挡角）决定，不再复用 `oh`。

## D5 前后排座椅共用一套 builder，朝向参数化 `代决`

- v11 的前排与二排是两份手抄的数学，约定相反，才出现"靠背角度与人体反向"。
- 决定：`seat(row, facing)` 一处实现；人体由**座椅自身坐标系**推导（躯干沿靠背轴线、大腿沿坐垫面、小腿落到地板/脚踏）。
- 朝向：`facing = +1`（朝车头） / `-1`（朝车尾，前排旋转后）。旋转是"绕座椅竖轴转 180°"，**坐垫位置不变**，不是镜像位移。

## D6 人体用关节链，不用手绘弧线 `代决`

- v11 的躺姿把头画成独立圆，与躯干断开 940mm。
- 决定：定义 175cm 关节表（下表），所有姿态（站/坐/躺/半躺）都是关节角组合，头永远接在颈关节上，永不分离。

| 关节 | 站立时离地高 | 段长 |
|---|---|---|
| 脚底 | 0 | — |
| 踝 | 80 | 小腿 400 |
| 膝 | 480 | 大腿 420 |
| 髋 | 900 | 躯干 520 |
| 肩 | 1420 | 颈+头 330 |
| 头顶 | 1750 | — |

坐姿：髋关节在坐垫面上方 90mm。躺姿：足跟→踝 80 → 膝 400 → 髋 420 → 肩 520 → 头顶 330，合计 1750。

## D7 二排联动机构必须被建模 `代决`

- 说明书第四章的核心创新是"靠背放倒 ↔ 腿托顶起"的纯机械联动，v11 完全没画。
- 决定：一个 `变形进度 fold ∈ [0,1]` 滑块驱动联动（0 = 标准坐姿，1 = 全平床）；靠背角与腿托角由连杆关系联动，**不允许**两者独立随意取值。这样"躺床"是一次真实的机构运动，而不是换一张图。

## D8 约束系统必须与画面同源 `已拍板`（用户要求"减少错误面"）

- 每条校验判据必须引用**同一个 builder 输出**的几何，禁止再写第二份数学。
- 修正 v11 的两条错误判据（床长忽略尾台、波峰全局计算），并把它们写进验收标准（见 `../../.scratch/01-blueprint-parametric/issues/01-fix-v11-geometry.md`）。

## D9 v12 引擎发现的新约束：床面前段必须完全落在前排靠背之后 `待用户确认`

- 腿托放平后，床面的最前段占据 `[xR − rCl − rLl, xR − rCl]`；前排靠背在床面高度处占据 `[xF + (床面高 − 前排座面高)·tan(fBa), +靠背厚]`。
- 两者在侧视图上必然相交，除非：`xR − rCl − rLl ≥ xF + (床面高 − 前排座面高)·tan(fBa) + 靠背厚`。
- 也就是说**前排 H 点、二排 H 点、腿托长、前排靠背角这四个量互相锁死**，不能各自独立取"舒服"的值。
- 默认解：xF=1760 / xR=2650 / rLl=250 / fBa=14° → 满足；`腿托长` 滑块的绿色可行区间正好是 150–250，拖长立刻变红。
- 含义：说明书第四章的"脚部空洞转为床面前段"在几何上成立，但**床面前段不能延伸到前排座椅底下**（座垫底面低于床面）。请确认是否接受"腿托较短（≈250）、床面从前排靠背之后开始"。

## D10 地板高 = 前离地 + 电池厚 `代决`

- 座舱地板取电池顶面；座垫面再抬 150（`base`，留出脚坑）。这是"前排座垫底面高于地板"的前提——否则二排脚无法滑入前排座下（说明书第四章的脚坑）。

## D11 做床必须旋转前排；床面从前座垫起算 `已拍板`

- 用户定调："make front seat when reversed seamlessly connects with the bed" 是最高优先级；"if bed requires front seat to rotate due to mechanical conflict, that's acceptable"。
- 床的构成（用户原话）：**前排座垫 + 二排腿托 + 二排座垫 + 二排靠背 + 固定隔板 + 可翻隔板 ≥ 1.75m**。
- 落地：
  1. `fold ≥ 0.5` 即进入床模式；床模式下前排**必须旋转 180°**（判据 C25c），否则腿托会插进前排靠背。
  2. 床面前段 = 旋转后的**前排座垫**，因此要求腿托前端与前座垫后缘**无缝**（判据 C25b：`|腿托前端 − 前座垫后缘| ≤ 40`），且前座面与床面**齐平**（C25a：`|差| ≤ 15`，用 `fLift` 升降前座对齐）。
  3. 前排旋转中心在座垫中点，故旋转前后座垫占地不变；"能不能转"只取决于扫掠圆，与朝向无关。
- 默认解：`rLl = xR − rCl − xF`，即腿托正好跨过脚部空洞 → 缝 2mm、齐平 0mm。

## D12 两个隔板：固定 + 可翻 `已拍板`

- **固定隔板 / 二层平台**：靠背放平后的尾端到可翻隔板铰点，恒为床面的一段，也是"干区二层"。
- **可翻隔板**：铰在固定隔板尾端，**0° 平铺补床尾**，**90° 立起成尾柱隔断**——用户原话："the thing you touch immediately when you open up trunk from the back；90° 时可以放两层高的货"。
- 落地：参数 `pAng`（0/90）、`flapLen`；判据 C26（固定平台 ≥200）、C26b（尾柱净高 ≥900，默认 1370）。

## D13 前排旋转但非床模式：留 600 净距 + 跨行桌板 `已拍板`

- 用户要求：两排之间至少留"两块 13 吋笔记本长边"的净距（≈600），能对面办公/打牌；桌板通过**车身墙面的榫卯卡口 + 从下层仓取出的隔板**自由搭建。
- 落地：判据 C27（会客模式下 `净距 ≥ 600`）；默认 `rowGap = 600`（xR=2830 / rCl=470 / 前座垫后缘 1760），桌板自动画在两排之间，台面离地 1060（= 座面 +280）。

## D14 顶横梁与投影 `已拍板`

- 用户："you didn't draw the top crossbar or space for projector… you need crossbar to decide where to put scrolled projector screen, then projector。希望幕布尽可能大，但实际上需要足够距离。"
- 落地：
  - **顶横梁 ×2** 画在升顶开口前后缘（也承担上铺板搭接的受力）。
  - **卷帘幕布**挂在顶横梁上（`scrX`），**投影仪**在车尾（`pjX`），投射比 `tr`。
  - 幕布宽度上限 = 吊柜之间净宽 `W − 2·lkD`（默认 1140）；所需投射距离 = `tr × 幕布宽`（1.5×1140 = 1710）。
  - 判据 C28（距离 ≥ 所需且投影仪在车内）、C28b（幕布下缘 ≥ 床面）。
  - 默认：50–51″（被**车宽**卡住，不是被距离卡住），投射距离 1730 ≥ 1710 刚好够。

## D15 轮位切片没有空间：前转向/48V/AC+溃缩件，后同轴三电 `已拍板`

- 用户："technically we have no space at the wheel slice, front is for turning mechanism and all the things that's crush-together-able like AC or 48V power, back is the coaxis Three Electric Assemblies, which have even fewer space. Probably no room for feet or for battery."
- 落地：
  - 侧视图把两个轴切片画成**红色机能包络**并标注占用物。
  - 判据 C29：电池要么**窄到能从左右轮包之间穿过**（`bw ≤ W−380`），要么**完全避开两个切片**（`b0 ≥ 前轴+包半径` 且 `b1 ≤ 后轴−包半径`）。默认走第一条（bw=1200 ≤ 1420）。
  - 判据 C30（橙）：前排脚是否落在前轮位切片内。默认**落在切片内**——即用户指出的"驾驶员的脚在前轮切片里"，要做掉必须把前轴前移或把前座后移 ~500mm，请用户决定。

## D16 说明书"45 度档位"的更正 `已拍板`

- 用户："45 degree: not like that"——45° 不是隔板斜靠，而是**二排靠背的半躺角**（由联动机构给到），用于行车观影。
- 落地：预设"行车观影"= `fold≈0.45`（靠背≈48°），隔板保持在 90° 或另行放平。
