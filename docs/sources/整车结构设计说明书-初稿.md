# 一、整车总览

本文档按从前到后的顺序，逐部件说明本车相对普通车的功能创新、使用要点、实现方式与取舍。

## 1\.1 整车定位

1. 整车以极小外轮廓容纳分时可变内部空间，通勤、观影、睡眠、露营、清洗多场景共用一车。

2. 变形机构全部采用纯机械结构，靠自重与人体微力驱动。

3. 全车空间按干区、湿区、脏区严格分层。

## 1\.2 全车功能创新清单

|创新功能|普通车|本车|
|---|---|---|
|前排旋转与中岛|前排座椅固定朝前|前排座椅驻车旋转，与中岛组成会客、用餐、办公区|
|二排联动大床|座椅分段放倒，床长受轴距限制|靠背与腿托纯机械联动，脚部空洞转为床面前段|
|后备箱双层|单层行李舱|一层湿区可冲洗，二层床面干区|
|隔板三档位|固定隔板或简单尾箱隔断|90度隔断、45度贵妃榻、全平床中段|
|升顶与纱窗|天窗或固定车顶|驻车升顶开启第三层空间，一体式纱窗防蚊通风|
|吊柜与三级储物|平整顶棚，储物集中于尾箱|两侧悬挑吊柜，前备箱、底层仓、吊柜干湿脏分层|

1. 前备箱

# 二、前备箱

## 功能创新

普通车的前舱以饰板覆盖结构梁，梁间空间被封闭浪费。本车让正面双溃缩大梁直接裸露，梁体之间的全部间隙释放为储物空间，溃缩安全结构与储物容量同时保留。

## 使用要点

1. 前备箱定位为全车一级脏区，适合放置耐脏、不怕灰、可承受轻微潮气的大件工具级物品。

2. 典型用途：户外装备、工具、备用物料、大件杂物。

3. 取放物品时自行避让梁体，安全结构保持完整。

## 实现方式

1. 正面双溃缩大梁完整保留，直接裸露布置。

2. 前备箱为超大整体空腔，仅两根梁体横贯分割。

## 取舍

前舱呈裸露工程观感；换取完整溃缩安全与极限储物体积。

# 三、前排旋转座椅与中岛

## 功能创新

普通车的前排座椅固定朝前，驻车时前后排之间只能保持行车朝向。本车前排座椅支持驻车旋转，与中岛配合后，车厢前部构成面向后排的会客、用餐与办公区域。

## 使用要点

1. 旋转操作仅在驻车状态下执行，行车时座椅锁止朝前。

2. 旋转前确认座椅周围人员与物品，收起安全带。

3. 旋转到位后确认锁止，再使用中岛台面。

## 实现方式

1. 座椅底座内置旋转转盘与锁止机构，驻车解锁后整椅旋转，到位后锁定。

2. 中岛为中央通道上的独立岛台，提供台面与储物，与旋转后的前排座椅组成围坐布局。

## 取舍

旋转机构增加座椅重量与离地高度，中岛占用中央通道空间，旋转功能仅在驻车时可用。

# 四、二排座椅放倒机构与联动机构

## 功能创新

普通车二排座椅放倒后仅形成倾斜面或局部平面，床长受轴距限制。本车二排靠背放倒的同时，连杆机构顶起腿托，把原本浪费的脚部空洞填平为床面前段，整车所需床长因此缩短，整车尺寸随之压缩。

## 使用要点

1. 行车时二排为标准乘员座椅，具备完整头枕、安全带锚点与刚性支撑。

2. 驻车变形：解锁靠背，靠背依靠自重向后倾倒，腿托同步顶起，脚部空洞转为床面前段。

3. 复位：下压腿托，杠杆反向回推靠背，自动归位并锁死。

4. 变形全程单人、原位、车内完成；靠背后倒时用户小腿位于运动轨迹内，提供天然阻尼缓冲，变形安静顺滑。

## 实现方式

二排变形由纯机械杠杆与重力联动完成，驱动来源为自重与人体微力，整车不依赖电动执行机构。

## 取舍

变形需手动操作，如需电动遥控需另行加装执行器；换取结构故障率极低、免维护与低成本。

# 五、轮毂、底盘与电池总成

## 功能创新

普通车的动力电池布置往往压缩座舱或尾舱空间。本车动力电池总成严格布置于前后轮轴之间，作为整车重心基准；前舱另设低压辅助电池，与动力电池总成分工；后轮相对普通车前移，车尾悬伸加长，释放车尾一二层立体空间。

## 使用要点

1. 电池系统为固定式布置，日常使用无需用户操作。

2. 整车重心位于轮轴距内，空载与常规载重姿态稳定。

## 实现方式

1. 动力电池总成置于前后轮轴之间。

2. 前轮上方布置转向机构与电控模块，后轮上方布置电机、悬挂与轮包。

3. 前舱布置低压辅助电池，负责整车低压用电。

## 取舍

外观比例观感让位于内部空间；换取稳定重心与车尾双层空间。

# 六、后备箱：L型隔板与一二两层

## 功能创新

普通车后备箱为单层行李舱。本车后备箱为双层结构：一层为可冲洗湿区，二层为床面干区，中间由L型隔板连接；隔板具备90度隔断、45度贵妃榻、全平床中段三档形态，一板三用。

## 使用要点

1. 90度档位：隔板直立，分割下层湿区与上层干区，兼作淋浴、冲洗与脏货隔离挡板。

2. 45度档位：隔板独立倾斜，二排保持标准坐姿，形成行车半躺观影与休憩位。

3. 全平档位：隔板放平，与二排床面、二层平台拼接为贯通大床。

4. 行车状态时隔板机械锁止于90度直立位，变形解锁操作仅在驻车状态下执行。

5. 一层放置脏鞋、泥土装备、工具、大件杂物，可直接冲洗。

6. 二层床垫可整板拆卸、外套可拆洗、可收纳至底层仓。

## 实现方式

1. 一层采用不锈钢裸金属工艺，底板带集水导流槽与标准化排水点位。

2. 二层床板基板为硬质金属结构，床垫以分段魔术贴条与四角织物绑带双重固定。

3. 隔板为机械三档位结构，配行车锁止机构。

4. 选装应急淋浴模块：净水箱置于底层，积水汇入集水坑，由低压小流量潜水泵抽至外置手提污水桶；站立淋浴区为车尾一二层连通的L型空间，洗完可在湿区擦干更衣，经尾门隐私帘遮挡后下车，或铺设防水垫跨隔板返回上层干区。

## 取舍

1. 金属湿区观感偏工程，保温弱于软包内饰；换取可冲洗、耐脏与防霉。

2. 隔板承载三档变形，需要机械锁止结构。

3. 床面为拼接结构，接缝处由床垫垫层覆盖。

# 七、升顶、纱窗与隐私

## 功能创新

普通车车顶固定，驻车通风依赖侧窗。本车驻车时可升起玻璃升顶，开启第三层立体空间；一体式拉链纱窗围幕实现全封闭防蚊与通风；投影幕布兼任前挡风超大隐私帘。

## 使用要点

1. 升顶在驻车时开启，行车时锁闭。

2. 纱窗为升顶一体式拉链围幕，驻车通风时拉合到位即可防蚊。

3. 隐私：前挡风用投影幕布遮挡，二排及后侧车窗使用独立加厚隐私帘，顶部透光不透视。

## 实现方式

1. 玻璃升顶机构，驻车开启、行车锁闭。

2. 一体式拉链纱窗围幕与升顶集成，全封闭密封。

3. 投影幕布与隐私帘通过车顶预埋点位安装。

## 取舍

升顶与纱窗仅在驻车使用；顶部机构增加整车重量。

# 八、吊柜与储物体系

## 功能创新

普通车顶棚平整，储物集中于尾箱。本车车顶左右两侧上角设置悬挑式固定吊柜，锚固于原厂车顶横梁，形成全车最高洁净干区；与前备箱、底层仓构成三级储物体系，干区、湿区、脏区物理隔离。

## 使用要点

1. 吊柜存放衣物、寝具、贴身物品与电子设备。

2. 车顶中间区域全空，180cm身高端坐、半躺、抬头均保有完整头部空间；最左右贴壁躺卧位置有轻微顶边。

3. 拓展件全部利用出厂预埋点位安装，可拆卸。

## 实现方式

1. 吊柜锚固于原厂车顶横梁，由横梁承重。

2. 天窗边框、顶梁与侧面上梁预埋统一标准螺孔与榫卯卡口。

3. 原生支持投影幕布悬挂、整车横跨式超大桌板卡接、小型灯架与拓展支架。

## 取舍

吊柜占用车顶两侧边角，贴壁躺卧位置轻微顶边；换取座舱中部完整净空与干区储物体积。

# 九、全车形态模式

## 模式一：城市通勤

前排座椅朝前锁止，二排为标准座椅，隔板直立锁止，升顶闭合，三层储物正常使用。

## 模式二：行车观影

二排正常载人，隔板倾斜45度形成贵妃榻，投影观影与休憩。

## 模式三：驻车会客办公

前排座椅旋转面向后排，中岛台面启用，形成围坐布局。

## 模式四：驻车大床

二排机械联动放平，隔板放平，与二层平台贯通为完整大床。

## 模式五：驻车露营

升顶开启，纱窗全封闭通风，三层空间全部可用。

## 模式六：干湿露营与应急清洗

隔板90度隔离，底层湿区独立工作，上层干燥人居区不受影响。

# 十、结构总结

1. 整车以极小外轮廓容纳分时可变内部空间。

2. 前排旋转、二排放倒与隔板变形均为纯机械结构。

3. 前备箱、底层仓、吊柜构成三级储物体系，干湿脏严格分层。

4. 整车结构自洽，可落地、可量产。
