## Acceptance criteria

**自动判定（`node scripts/check.mjs 蓝图-参数化-v12.html` 全绿）**

1. `rBa` 从 −20° 扫到 65°：人体躯干上端 x **单调向车尾**移动；躯干轴与靠背轴夹角 ≤8°；前排同向同量级。
2. `fold` 从 0 扫到 1：靠背角与腿托角按连杆关系联动（两者非独立），`fold=1` 时床面连续平段与 `bedAssembly` 自报长度一致。
3. 任意模式、任意参数：轮包弧心与轮心同高（误差 <1mm），弧半径 = 轮半径 + 60，且包顶 > 轮顶。
4. 任意模式：`occupant` 关节链中颈关节与头心距离 ≤ 头半径+5mm（头身不得分离）。
5. 升顶站立态：`床面 + 1750 + 60 ≤ H + pr`，且站姿人体包围盒不超顶棚。
6. 升顶上铺态：上铺板面的躺姿人体包围盒完全位于 [原车顶面, 顶棚] 之间，头顶余量 ≥150。
7. 座垫/靠背的绘制厚度 = 对应滑块值 ±5mm；改滑块时人体高度随之变化。
8. `H > 2000` 判红（决策 D1）；`H ≤ 2000` 时坐姿净空 ≥ `床面+900+60`。
9. 电池判据为**宽度**判据（`bw ≤ 轮包内间距`），且侧视图中不再出现"电池/人体与轮胎圆相交"的判据。
10. 中岛 x 可在 800–3600 独立取值（不依赖前排座垫跨度）；台面离地 700–760 判绿。
11. 20000 次随机采样全绿比例 ≥0.5%，且存在 `L ≤ 3700` 的全绿解。

**人工/混合**

12. 点选说明书第九章 6 种形态 + 升顶 3 态，参数值确实改变、可回退（Ctrl+Z），非仅切换显示。
13. 说明书第 2/6/8 章图元可见：前备箱、L 型隔板 0/45/90 三档、两侧吊柜。
14. 每个滑块旁有数字输入框 + 轨道上的有效区间绿带；拖出绿带时给出"该动哪个滑块"的提示。
15. 刷新后参数保留；可导出/导入 JSON；URL hash 可分享；无 console 报错。
